# HR Interview Copilot 🤖

An end-to-end HR interview scheduling solution built with Microsoft Copilot Studio, Power Automate, SharePoint, Teams, and Outlook.

## ✨ Features

✅ Candidate lookup via InterviewID

✅ Interviewer availability search

✅ Dynamic interview slot selection

✅ Automatic Teams meeting creation

✅ Automated email invitation delivery

✅ SharePoint status synchronization
