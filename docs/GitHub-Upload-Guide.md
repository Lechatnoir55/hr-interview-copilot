# GitHub Upload Guide

## 1. Suggested Repository Name

```text
copilot-studio-hr-interview-assistant
```

## 2. Suggested Repository Description

```text
A Microsoft Copilot Studio and Power Automate portfolio project for HR interview scheduling with SharePoint, Teams, and Outlook.
```

## 3. Uploading via the Web Interface

1. Create a new Public Repository on GitHub.
2. Set the repository name to `copilot-studio-hr-interview-assistant`.
3. Unzip this project archive.
4. On the repository page, choose to upload files.
5. Upload `README.md`, the `docs` folder, and the redacted `images` folder.
6. A suitable commit message:

```text
Add HR Interview Assistant portfolio documentation
```

## 4. Uploading Screenshots

Place the redacted images in:

```text
images/
├── 01-agent-overview.png
├── 02-agent-instructions.png
├── 03-booking-topic.png
├── 04-availability-workflow.png
├── 05-teams-workflow.png
├── 06-test-conversation.png
└── 07-sharepoint-result.png
```

Then reference them in the README:

```markdown
![Agent overview](images/01-agent-overview.png)
```

## 5. Pre-Upload Checklist

- [ ] Images have the environment identifier in the address bar redacted
- [ ] No real candidate names or email addresses
- [ ] No real interviewer email addresses
- [ ] No Tenant ID, Site URL, connections, or tokens
- [ ] README states that this is a learning and portfolio project
- [ ] Sample data uses `example.com`
- [ ] Mermaid architecture diagrams render correctly on GitHub
